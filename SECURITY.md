# Security Policy

## Reporting Security Vulnerabilities

The Maidan Desk team takes software security seriously. If you discover a vulnerability or security flaw, please report it responsibly.

### Supported Versions

| Version | Supported |
|---|---|
| Latest `main` / `client` | :white_check_mark: |
| Deployed Live App | :white_check_mark: |
| Archived `legacy/` | :x: (Deprecated / Archived) |

### How to Report

Please **DO NOT** report security vulnerabilities via public GitHub issues or discussions.

Instead, please send an email directly to **kamranakmal749@gmail.com** with:
1. A description of the issue and potential impact.
2. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
3. Any suggested remediations or patches if available.

### Handling Process

1. We will acknowledge receipt of your report within 48 hours.
2. We will investigate and confirm the vulnerability.
3. Once resolved, we will publish a patch and release an advisory giving proper credit to the reporter.
